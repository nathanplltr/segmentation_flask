Documentation

Ce site permet de détecter automatiquement des objets maritimes (bateaux, voiliers, kayaks, bouées) sur des images de caméra de surveillance. Voici comment il fonctionne et comment l'utiliser.

🏠 Accueil

La page d'accueil présente le projet. C'est le point de départ du site.

🔍 Analyse

C'est la page principale. Sélectionnez une image déjà présente sur le serveur, puis cliquez sur le bouton d'analyse. Le site traite alors l'image et affiche trois résultats : l'image originale, le masque de segmentation (la zone eau isolée), et l'image annotée avec les objets détectés encadrés et étiquetés.

📊 Analyse des régions

Cette page affiche le détail de chaque objet détecté lors de la dernière analyse : son type, son score de confiance, et sa position dans l'image. Elle se met à jour automatiquement après chaque nouvelle analyse.

✏️ Annotation manuelle

Cette page vous permet de sélectionner une image et de dessiner manuellement des zones pour les annoter. Utile pour corriger ou compléter une détection automatique qui aurait manqué un objet.

🔒 Verrous

Cette page présente les difficultés rencontrées pendant le développement et les limites actuelles de l'application.

⚙️ Comment ça marche ?

Le site est construit avec Flask, un framework Python léger pour créer des applications web. Quand vous lancez une analyse, Flask envoie l'image à un script de traitement (segmentation_logic.py) qui utilise un modèle d'intelligence artificielle appelé YOLOv8 (version légère yolov8n).

Ce modèle analyse l'image et tente de localiser des objets maritimes parmi quatre catégories : voilier, kayak/paddle, bateau à moteur et bouée. Un filtre supplémentaire est appliqué pour ignorer les zones vertes (végétation, herbe) qui pourraient être confondues avec des objets sur l'eau. Seules les détections dépassant 50 % de confiance sont affichées.

Les résultats sont ensuite renvoyés au site et affichés directement dans votre navigateur.
